# T-001.6 — Write `stack.md`

## Description
Architect documents every framework, service, and major dependency the project uses **and the reason it was chosen**. A future engineer should be able to answer "why this and not the alternative?" from this file.

## Acceptance criteria
- [ ] `/docs/stack.md` exists.
- [ ] Lists language(s), frontend framework, backend framework, database, cache, queue, authentication provider, Continuous Integration provider, hosting platform, monitoring stack, secret manager, package manager.
- [ ] Each entry has a one-paragraph "why this" with the alternatives considered.
- [ ] Marks any "load-bearing" dependencies (replacing them would be expensive).
- [ ] Notes license posture for major dependencies.
- [ ] All 9 agents have signed off.
