# T-003 — Adopt the agentic starter as this repo's playbook

## Description
tldw is being used as a hackathon demo of the agentic playbook building a real product.
The demo branch `hackathon/demo` is thrown away afterwards and never merges into `main`.

Until now this repo followed the older, one-page playbook in the owner's home folder (`~/CLAUDE.md`), which describes 8 agents. The current methodology is the agentic starter at `~/personal/agentic-starter-main`, commit `bb9406f` (2026-11-09). It adds:
- a 9th agent, the Review Coordinator;
- per-agent redlines;
- the `tasks/` ledger;
- the code-grounded `/docs` with its consensus gate;
- git hooks and CI that enforce the procedure.

This task installs it on the demo branch, adapted to this repo, so that the demo follows the current methodology. The owner decided on 2026-11-12:
1. Build the Tier 1 docs before the event. That is T-001, the next PR.
2. CI runs the starter's checks plus tldw's own tests.
3. `hackathon/demo` is the protected branch: the hooks treat it like `main`, and a GitHub branch rule requires the checks. The rule is added once the checks have reported on a PR (`ADOPTING.md` § 5).
