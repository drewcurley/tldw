# T-012 — Fix documentation and comments outside /docs that the bootstrap found wrong

## Description
Found while drafting the Tier 1 docs (T-001). These are recorded facts, not changes made by T-001 (plan rule 9). Each item cites its source. The docs that record it are listed in `docs/contracts.md`, `docs/architecture.md` § 7, `docs/data-model.md`, `docs/testing.md` and `docs/deployment.md`, in their follow-ups sections.

## Items
- [ ] The README and the options page give `tldw config llm_cmd "…"` (`README.md:76-77`, `:81`; `extension/options.js:61-63`). Measured, that form prints the usage line and exits 1; the working form is `tldw config set llm_cmd`.
- [ ] `extension/README.md:104-107` overstates the Origin check and says "nothing else leaves your machine", but Hugging Face model downloads and the direct caption fetch do leave it.
- [ ] `.github/CODEOWNERS:12` says one human approver is required; this repo requires 0. `.github/CODEOWNERS:31` names `.gitattributes`, which isn't tracked.
- [ ] `AGENTS.md:482`, `.claude/agents/review-coordinator.md` and `.github/pull_request_template.md:60` say `<branch>`, where `docs/reviews/README.md` defines a folder rule.
- [ ] Stale code comments: the request log *does* include the query string (`server.py:962-963`); `_transcript_cache` holds four items, not three (`server.py:38`); the `_tx_jobs` key includes the model (`server.py:64`); `tests/test_claude_client.py` says "three copies" of the model list, and there are four.
- [ ] The Options footer (`extension/options.html:79-80`) and `README.md:205` say tldw "runs entirely on your own machine". With the default backend, the transcript and questions go to Anthropic (`docs/architecture.md` § 8), so read as a privacy claim it overstates. Found while drafting `docs/ux.md` (T-001.7).
- [ ] `usage.py:57` lists `video` as an `Interaction` kind, but no code opens a `video` interaction (the call sites are `server.py:501`, `:1175`, `:1263`, `:1619`, `:1792`); `video` rows are written directly by `note_video` (`usage.py:201-203`). Found while drafting `docs/domain.md` (T-001.3).
- [ ] `README.md:14` calls a local backend "fully offline", but YouTube (metadata and captions, when the page doesn't supply them) and Hugging Face (first-use model downloads) are contacted whatever the backend (`docs/architecture.md` § 8). Found while drafting `docs/domain.md` (T-001.3).
- [ ] `README.md:132` says the extension exposes "the same dial" as `--ratio`. True for video mode only: in text mode `--ratio` shapes the written summary, which the extension's Key moments length never affects (`extension/options.html:54-55`), and the extension sends no summary ratio (`extension/background.js:152`). Found while drafting `docs/domain.md` (T-001.3).
- [ ] `README.md:225` gives `tldw config ytdlp_cookies chrome`, which also exits 1 (measured by DevOps, Tier 2). **Already fixed on `main` in PR #13** (with `README.md:76-81` and `options.js:63`); this fork was cut from `main` before that fix.
- [ ] The `_tx_jobs` comment at `server.py:64` says it is keyed by video id, but it is keyed by `(video_id, model)` (`server.py:196`; Backend, Tier 2).
