# T-001.10 — Set up `runbooks/` skeleton

## Description
DevOps creates `/docs/runbooks/` with the minimum set of on-call procedures: incident severity definitions, paging escalation, common-failure playbooks, and a runbook template so future engineers add new ones consistently.

## Acceptance criteria
- [ ] `/docs/runbooks/README.md` exists with index + template pointer.
- [ ] `/docs/runbooks/_TEMPLATE.md` exists.
- [ ] `/docs/runbooks/incident-severity.md` defines Sev1–Sev3 (or your org's scheme) with response-time SLAs.
- [ ] `/docs/runbooks/on-call.md` documents rotation, paging tool, escalation tree.
- [ ] At least one concrete playbook drafted for a known failure mode (e.g. database failover, dependency outage, deployment rollback).
- [ ] All 9 agents have signed off.
