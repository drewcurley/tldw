# T-010 — Add guarding tests for the unguarded contracts

## Description
Found while drafting the Tier 1 docs (T-001). These are recorded facts, not changes made by T-001 (plan rule 9). Each item cites its source. The docs that record it are listed in `docs/contracts.md`, `docs/architecture.md` § 7, `docs/data-model.md`, `docs/testing.md` and `docs/deployment.md`, in their follow-ups sections.

## Items
- [ ] There's no test for the unknown-route `404` (`server.py:980`, `:1017-1019`) or the `501` on an unhandled method (sent by the stdlib `BaseHTTPRequestHandler`; no line in `server.py`).
- [ ] There's no behavioural test of the speak, ask, segments and preview message flows, `TLDW_INVOKE`/`TLDW_ERROR`, `video.html5-main-video`, or the `" (cached)"` suffix.
- [ ] There's no test of `serve` through `cli.main`, `config unset`, or exit code 130.
- [ ] There's no test of `TLDW_TOKEN`, `HF_HOME` or `HF_HUB_DOWNLOAD_TIMEOUT`.
- [ ] There's no test of `options.js` load/save, or of the two `DEFAULTS` objects that differ.
- [ ] The mirrored lists aren't compared with the server's: `WHISPER_POLICIES`, `VOICE_FALLBACK`/`VOICE_OPTIONS` against `audio.VOICES`, and the `<option>` lists in `options.html`.
- [ ] The manifests (versions equal, `host_permissions` coupled to 8765), the five version fields, and the copy list in `extension/build-firefox.sh` are unguarded.
- [ ] Security invariants with no test: the loopback refusal, chunked → 400 and 411, the constant response headers (`X-Content-Type-Options`, `Cache-Control`), and the caption host allowlist. (413 is tested at `tests/test_server.py:151`; the token-file mode is tested on POSIX only, `tests/test_server.py:771-790`.)
- [ ] Bare `src.indexOf()` slices in `tests/js/render_checks.js` can pass on a missing marker, and renaming the `PANEL_*_MS` constants silently turns off the test speed-up.
- [ ] `tests/test_claude_client.py::test_a_silent_claude_is_killed_at_its_deadline` failed once in five full-suite runs on 2026-11-12 and passed alone and on every re-run. It gives the fake CLI 0.5 s to start and write its pid file (`tests/test_claude_client.py:438-447`), which a loaded machine can miss. Per `docs/testing.md`'s flake policy it must be fixed, not re-run.

## Acceptance criteria
- [ ] Each item above is fixed with a guarding test, or recorded as an accepted decision (an ADR when it crosses a redline), or answered by the owner.
- [ ] Every doc that records an item is updated in the same PR, under the `/docs` gate.
