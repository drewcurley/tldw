# T-014 — Make data stores and extension state robust

## Description
Found while drafting the Tier 1 docs (T-001). These are recorded facts, not changes made by T-001 (plan rule 9). Each item cites its source. The docs that record it are listed in `docs/contracts.md`, `docs/architecture.md` § 7, `docs/data-model.md`, `docs/testing.md` and `docs/deployment.md`, in their follow-ups sections.

## Items
- [ ] `config.json` writes aren't atomic (`config.py:31`, `:40`). A torn write reads as `{}`.
- [ ] The cache `.tmp` name is per key, not per writer (`txcache.py:84`, `:124`, `:158`).
- [ ] `lang` isn't part of any cache key (`core.py:56`).
- [ ] The `youtube-tldw-` and `youtube-tldw-tx-` temp dirs are never swept; only `youtube-tldw-audio-*` is (`hygiene.py:92`).
- [ ] `usage.jsonl` grows without bound, and `tldw cache` doesn't report it.
- [ ] No fingerprint covers the shape of the cached summary payload (`_to_payload`) or the segment items.
- [ ] The extension's in-memory `cache`, `audioCache` and `previewCache` have no eviction. The summary map is keyed by video id only (`background.js:25-26`, `:131`, `:449`).
- [ ] The worker's `DEFAULTS.voice` is never used, and its `DEFAULTS` has no `closeAction` (`background.js:10`, `:47-51`).
- [ ] The panel's voice picker never asks `/voices` (`content.js:1005`).
- [ ] `PROMPT_FINGERPRINT` covers only `_TEXT_BODY`, `_TEXT_PROMPT`, `_TEXT_PROMPT_STREAM` and `_TEXT_REDUCE_PROMPT` (`summarize.py:144`). `_ratio_clause`, `_metadata_header` and `SINGLE_PASS_CHARS` shape summaries but aren't in the summary key, so editing one serves stale summaries for up to 14 days (`summarize.py:17`, `:151`, `:241`). `SEGMENT_FINGERPRINT` also misses `_metadata_header` and `SINGLE_PASS_CHARS` (`core.py:35-42`).
- [ ] A non-numeric `video_ms` or `read_ms` in one `usage.jsonl` row makes `usage.stats()` raise (`usage.py:218-219`), uncaught at `server.py:1234`, `:1328` and `:1369`.
- [ ] Config readers assume strings: `.strip()` on `llm_cmd` and `ytdlp_cookies` (`claude_client.py:210`, `metadata.py:53-54`), `whisper_model in VALID_MODELS` raises on a list (`whisper_transcribe.py:79`), `Path(output_dir)` raises on a non-string (`cli.py:31`).
- [ ] `whisper_max_minutes` of 0 or below is clamped to 1 minute rather than refused or defaulted (`server.py:133`).
- [ ] `tldw cache clean` skips cache files it can't read or that lack `saved_at` (`hygiene.py:197`, `:215-216`); only the cap or an overwrite removes them.
- [ ] Third-party stores tldw causes: yt-dlp's own cache (tldw never passes `--no-cache-dir`) and the browser cookie database read when cookies are configured (`metadata.py:48-55`). Location, layout and retention are `UNKNOWN — needs human confirmation`.
