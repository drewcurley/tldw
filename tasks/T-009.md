# T-009 — Close the panel's keyboard and accessibility gaps

## Description
Found while drafting the Tier 1 docs (T-001). These are recorded facts, not changes made by T-001 (plan rule 9). Each item cites its source. The docs that record it are listed in `docs/contracts.md`, `docs/architecture.md` § 7, `docs/data-model.md`, `docs/testing.md` and `docs/deployment.md`, in their follow-ups sections.

## Items
- [ ] `.regen` has no `aria-label`.
- [ ] `.ts` citation links can't be activated from the keyboard.
- [ ] The Tab trap's last element can be the hidden `.asksend`, and the trap ignores links.
- [ ] The main error and progress views aren't live regions.
- [ ] Shift+Tab from the focused panel (`tabindex="-1"`, `content.js:267`) leaves the modal, because the panel is not the trap's `first` (`content.js:317`).
- [ ] The skip pill's buttons use `all:unset` (`content.js:1738`), so they show no focus ring.
- [ ] The Whisper install command is near-invisible in light mode: `.installhint` sets text `#e9e9ea` on an 18 % grey wash over the white panel, about 1:1 by arithmetic on the declared CSS (`content.js:182-185`, `:143`). Found while drafting `docs/ux.md` (T-001.7).
- [ ] The corner notice (`#tldw-toast`) is a clickable `div` with no `tabindex` or button role, so it can't be used from the keyboard; it goes after 12 s (error) or 20 s (ready) (`content.js:753-777`). Found while drafting `docs/ux.md`.
- [ ] The Options page's `<html>` has no `lang` (`options.html:2`), and nothing in `extension/` reacts to `prefers-reduced-motion` (spinners, ring and creeping bar, `content.js:168-171`, `:239-246`, `:725-734`). Found while drafting `docs/ux.md`.
- [ ] Contrast and target size (WCAG 2.5.8) have never been measured. Arithmetic on the declared hex values alone puts `#888` on `#fff` (3.5:1), `#777` on `#fff` (4.48:1), the error colour `#c0392b` on the dark panel (3.0:1) and Options `Saved` `#0a0` on `#fff` (3.1:1) under 4.5:1 (`docs/ux.md`, Accessibility → Contrast). Found while drafting `docs/ux.md`.
- [ ] All of these were found by reading the code; check them in a real browser.
