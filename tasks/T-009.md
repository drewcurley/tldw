# T-009 — Close the panel's keyboard and accessibility gaps

## Description
Found while drafting the Tier 1 docs (T-001). These are recorded facts, not changes made by T-001 (plan rule 9). Each item cites its source. The docs that record it are listed in `docs/contracts.md`, `docs/architecture.md` § 7, `docs/data-model.md`, `docs/testing.md` and `docs/deployment.md`, in their follow-ups sections.

## Items
- [ ] `.regen` has no `aria-label`.
- [ ] `.ts` citation links can't be activated from the keyboard.
- [ ] The Tab trap's last element can be the hidden `.asksend`, and the trap ignores links.
- [ ] The main error and progress views aren't live regions.
- [ ] Shift+Tab from the focused panel (`tabindex="-1"`, `content.js:267`) leaves the modal, because the panel is not the trap's `first` (`content.js:317`).
- [ ] The skip pill's buttons use `all:unset` (`content.js:1738`), so they show no focus ring.
- [ ] All of these were found by reading the code; check them in a real browser.

## Acceptance criteria
- [ ] Each item above is fixed with a guarding test, or recorded as an accepted decision (an ADR when it crosses a redline), or answered by the owner.
- [ ] Every doc that records an item is updated in the same PR, under the `/docs` gate.
