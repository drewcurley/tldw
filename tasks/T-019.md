# T-019 — Name the hackathon extension "TL;DW — Hackathon"

## Description
**The owner's request, 2026-11-12:** distinguish the hackathon version from the normal one, so both can stay loaded in the owner's Chrome without a second profile. The owner: only one is enabled at a time, both use the same port, and "this hackathon version is throwaway at the end of the week anyway".

This is a contract change (`docs/contracts.md` documents the manifest `name`). It is folded into the Tier 2 docs PR, which runs the full 9-agent cycle.

## Acceptance criteria
- [x] `name` is `TL;DW — Hackathon` in both `extension/manifest.json` and `extension/manifest.firefox.json`, and the `name` row in `docs/contracts.md` matches. A guard test in `tests/test_docs_contracts.py` checks this.

## Out of scope
- `default_title`, `host_permissions`, the default port, the version and the defaults all stay as they are (owner: same port).
- Side-by-side installs in Firefox: `gecko.id` is unchanged, so the hackathon build replaces the normal one there. The request is about Chrome.

## Notes
- This task goes away with the fork at the end of the hackathon.
- With both extensions installed, the browser holds two plain-text copies of the token (Architect). That is recorded in T-004, which is deferred.
